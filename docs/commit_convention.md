# Конвенція повідомлень комітів (SDD Workflow)

Формат повідомлення:
`<префікс>: <стислий опис українською або англійською мовою>`

## Дозволені префікси артефактів та дій:
* `spec:` — зміни та доповнення до вимог, задуму системи або артефактів SRS у каталозі `/spec`.
* `test:` — додавання або модифікація модульних, інтеграційних чи контрактних тестів у каталозі `/tests`.
* `feat:` — реалізація функціонального коду або бізнес-логіки системи у каталозі `/src`.
* `docs:` — оновлення проєктної документації, інструкцій, архітектурних схем у каталозі `/docs`.
* `logs:` — журнали взаємодії з агентом, записи про сесії та розв'язання конфліктів у каталозі `/logs`.
* `gate:` — перевірка критеріїв якості, затвердження етапів, налаштування CI/CD або валідаційних скриптів.
