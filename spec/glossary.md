# Глосарій термінів (Glossary)

Даний документ містить визначення основних термінів та понять, що використовуються у специфікації вимог (SRS) та системній документації проєкту «Онлайн-каталог локальної бібліотеки».

| Термін (UA) | Англійський аналог | Визначення та контекст використання |
| :--- | :--- | :--- |
| **Книга / Бібліографічний запис** | Book Title / Bibliographic Record | Загальний запис про друковане видання в каталозі (включає назву, автора, ISBN, жанр, анотацію). Описує твір незалежно від кількості його фізичних примірників. |
| **Примірник книги** | Book Copy / Physical Item | Конкретна фізична одиниця книги з унікальним інвентарним номером або штрихкодом, що належить до бібліотечного фонду. |
| **Статус примірника** | CopyStatus | Поточний стан фізичного примірника книги (`AVAILABLE`, `BORROWED`, `RESERVED`, `IN_REPAIR`, `LOST`). |
| **Агрегований стан доступності книги** | TitleAvailability | Динамічно обчислюваний стан доступності книги для читачів у результатах пошуку (`AVAILABLE`, `UNAVAILABLE`, `OUT_OF_STOCK`). Залежить від наявності та статусів усіх пов'язаних примірників. |
| **Заархівована книга** | Archived Book (`isArchived`) | Стан бібліографічного запису книги, при якому вона приховується з публічного каталогу читачів. Застосовується бібліотекарем у разі втрати всіх примірників без наміру поновлення. |
| **Внутрішній облік інвентарю** | Inventory Management | Набір адміністративних функцій для бібліотекаря щодо додавання книг, реєстрації нових примірників та зміни їхніх статусів. |
| **Публічний онлайн-каталог** | Public Online Catalog | Користувацький веб-інтерфейс для пошуку, фільтрації та перегляду наявності літератури читачами без можливості прямого редагування даних. |
