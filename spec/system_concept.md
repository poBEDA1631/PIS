# Онлайн-каталог локальної бібліотеки

## Призначення та мета системи
Система призначена для ведення електронного обліку книжкового фонду локальної бібліотеки, надання користувачам можливості швидкого пошуку літератури та перегляду актуального статусу доступності примірників.

## Межі системи (System Boundaries)
* **Входить до системи:** онлайн-каталог для читачів (пошук, фільтрація, перегляд наявності та статусів примірників) та функціонал внутрішнього обліку книжкового фонду для бібліотекаря (ручне управління каталогом та зміна статусів примірників).
* **НЕ входить до системи (Out of Scope):** повноцінний модуль циркуляції (реєстрація та формуляри читачів, автоматичний розрахунок термінів видачі, штрафів чи пені).

## Основні сутності предметної області
* **Книга (Book / Title):** бібліографічний запис (назва, автор, ISBN, жанр/категорія, анотація, прапорець `isArchived`).
* **Примірник (Book Copy / Item):** конкретна фізична одиниця книги з унікальним інвентарним номером або штрихкодом.
* **Жанр / Категорія (Genre):** таксономія для класифікації літератури.
* **Статус примірника (Copy Status):** поточний стан фізичної книги.
* **Агрегований стан доступності (Title Availability):** обчислюваний статус наявності примірників книги для читачів (`AVAILABLE`, `UNAVAILABLE`, `OUT_OF_STOCK`).

## Базові функціональні вимоги
* **Пошук та фільтрація:** пошук книг за назвою, автором, ISBN та фільтрація за жанрами. Заархівовані книги (`isArchived = true`) приховуються з публічного пошуку для читачів.
* **Облік статусів видачі та обслуговування:** кожен примірник повинен мати визначений життєвий цикл і статус.
  * Актуальний перелік статусів примірника:
    * `AVAILABLE` (доступна на полиці),
    * `BORROWED` (видана читачеві),
    * `RESERVED` (зарезервована),
    * `IN_REPAIR` (на реставрації / технічному обслуговуванні),
    * `LOST` (втрачена / списана).
  *Правила для статусу `IN_REPAIR`:*
    * Перехід у статус `IN_REPAIR` можливий зі статусів `AVAILABLE` (виявлено пошкодження під час інспекції) та `BORROWED` (повернення пошкодженої книги читачем).
    * Бронювання (`RESERVED`) примірника у статусі `IN_REPAIR` суворо заборонено через непередбачуваність термінів ремонту.
* **Каталогізація та Архівування:** перегляд списку примірників для конкретної книги з відображенням їхнього статусу. Бібліотекар має право архівувати книги (`isArchived = true`), у яких всі примірники списані (`LOST`).
