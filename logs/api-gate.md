## 1. Чекліст 10 критичних критеріїв верифікації (API-GATE Acceptance Criteria)

| № | Критерій верифікації | Стан | Підтвердження та артефакти |
| :-: | :--- | :---: | :--- |
| **1** | **Простежуваність вимог (REQ-ID Traceability)** | **PASSED** | Усі 6 ендпоінтів мають явні посилання на `REQ-F-001`..`004`, `REQ-NF-002`..`003` у полях `summary` та `description`. Оновлено `spec/traceability_matrix.md`. |
| **2** | **Відповідність глосарію (Ubiquitous Language)** | **PASSED** | Назви сутностей та атрибутів (`Book`, `Copy`, `inventoryNumber`, `TitleAvailability`, `CopyStatus`, `isArchived`) на 100% узгоджені зі `spec/glossary.md`. |
| **3** | **RESTful архітектура та ресурси** | **PASSED** | Іменники у множині (`/books`, `/copies`), версіонування `/api/v1`, плоский доступ за штрихкодом `/copies/{inventoryNumber}/status` та семантичні action-ендпоінти архівування. |
| **4** | **Схеми даних (components/schemas)** | **PASSED** | Повноцінно формалізовано моделі `Book`, `Copy`, `TitleAvailability` (enum), `CopyStatus` (enum), `CopiesSummary`, `Pagination`, `BookDetail`, `BookListItem`. |

| **6** | **Розмежування доступу та безпека (REQ-NF-003)** | **PASSED** | Визначено схему `BearerAuth` (JWT) для ролі «Бібліотекар» на операціях зміни статусу та архівування. Публічні маршрути явно марковано як `security: []`. |

| **8** | **Автоматична валідація контракту (Linting)** | **PASSED** | Специфікація пройшла валідацію через `@redocly/cli lint` без помилок та без попереджень (`0 errors, 0 warnings`). |
| **9** | **Працездатність локального Mock API** | **PASSED** | Контракт успішно завантажено та розгорнуто локальним mock-сервером `@stoplight/prism-cli mock` на порту 4010. |
| **10** | **Успішне тестування сценаріїв (Acceptance Tests)** | **PASSED** | Виконано та підтверджено 3 позитивні сценарії (пошук, картка книги, зміна статусу на `IN_REPAIR` — 200 OK) та 2 негативні сценарії (422 ProblemDetails, 401 Unauthorized). |
