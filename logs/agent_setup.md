# Журнал конфігурації кодингового агента

* **Дата фіксації:** 2026-09-16
* **Обраний інструмент:** Antigravity / GitHub Copilot Agent

## 1. Клас інструменту
* **Тип:** Автономний кодинговий агент середовища розробки (IDE Agent / Workspace-aware Assistant).
* **Модель:** Комбінація мультимодальних LLM із контекстним аналізом робочого простору.

## 2. Спосіб доступу до репозиторію
* **Рівень інтеграції:** Прямий доступ до локальної файлової системи через IDE/CLI.
* **Контекст проєкту:** Автоматичне індексування дерева файлів, семантичний пошук по файлах репозиторію (RAG на рівні проєкту), читання специфікацій `/spec` та документації.

## 3. Дозволені операції в робочому середовищі
* **Читання:** Аналіз структури каталогів, парсинг артефактів специфікації, перегляд коду та тестів.
* **Генерація та редагування:** Внесення змін у наявні файли та створення нових кодових одиниць за запитом.
* **Виконання команд:** Запуск лінтерів, тестів та базових команд перевірки цілісності (у пісочниці або під контролем розробника).
* **Контроль з боку людини:** Будь-які модифікації файлів обов'язково проходять через стадію верифікації за допомогою `git diff` перед фіксацією в коміт.
